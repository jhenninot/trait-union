# Logos Trait d'union

| Fichier | Usage |
|---|---|
| `logo-complet.svg` / `.png` | Logo avec le nom, fond clair (1260×360) |
| `logo-complet-sombre.svg` / `.png` | Logo avec le nom, mode sombre |
| `icone.svg` / `.png` | Icône seule, fond clair (1024×1024) |
| `icone-sombre.svg` / `.png` | Icône seule, mode sombre |

Préférer les SVG ; les PNG servent là où le vectoriel n'est pas accepté.
